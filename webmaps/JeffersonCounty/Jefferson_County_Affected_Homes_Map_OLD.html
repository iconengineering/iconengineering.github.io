About This Map

The Jefferson County Affected Homes application combines active structure locations with floodplain, municipal boundary, and river and stream information.

  • Use the map controls to search, zoom, identify features, and manage layers.
  • The chart updates to show structures by flood zone inside the current map view.
  • Use the AI Assistant to explore supported map layers with natural-language questions.

This map is intended for planning and informational purposes. Results depend on the available source data and should not replace an official floodplain determination or site-specific engineering analysis.
